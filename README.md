# Services

A small web app for the DTU course Architectural Masterclass. It reads the MEP model (IFC) of a building in the browser and gives the same values and images for every project: data as CSV and JSON, isometric pictograms as SVG and PNG, and a document of three pages.

Open the app, drop the MEP IFC of your project, check and complete the values, export. Everything runs on your own computer. No file is uploaded.

Built with web-ifc (MPL 2.0), pdf.js (Apache 2.0) and fflate (MIT), included in `vendor/`.
